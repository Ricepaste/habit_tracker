## 前置準備

1. 清除瀏覽器 localStorage 或使用無痕視窗開啟應用
2. 首次載入應自動匯入 `test_data.json` 測試資料集（4 個習慣、含專注紀錄與獎勵背包）
3. 若未自動載入，可手動拖曳 `test_data.json` 到備份管理區的 drop zone

測試資料內容說明：

| 習慣 | 累積次數 | 抽獎券設定 |
|------|----------|------------|
| 每日閱讀 | 45 次 | 每 10 次 1 張券（已領 4 張） |
| 深蹲運動 | 120 次 | 每 20 次 1 張券（已領 6 張） |
| 冥想練習 | 15 次 | 未啟用 |
| 日記寫作 | 8 次 | 每 5 次 1 張券（已領 1 張） |

- 專注總時數：約 415 分鐘（接近 420 分鐘的抽獎券門檻）
- 持有抽獎券：3 張
- 背包內有 4 件獎品（2 Rare / 1 Epic / 1 Legendary）

## 一、追蹤頁面 (Habits)

### 1.1 習慣清單渲染
- [ ] 四個習慣卡片正確顯示，含今日累積與總計數字
- [ ] 已啟用抽獎券的習慣顯示「再累積 X 次抽獎券」提示（橘色）
- [ ] 未啟用抽獎券的習慣（冥想練習）不顯示提示

### 1.2 紀錄成就
- [ ] 點擊「紀錄成就」按鈕，該習慣今日 / 總計數字 +1
- [ ] 底部出現綠色復原橫幅「已紀錄成功！」
- [ ] 5 秒後復原橫幅自動消失

### 1.3 撤銷紀錄
- [ ] 點擊復原橫幅的「復原」按鈕，數字恢復
- [ ] 撤銷後橫幅消失

### 1.4 抽獎券自動發放
- [ ] 對「日記寫作」再紀錄 2 次（目前 8 次，threshold=5，已領 1 張，第 10 次應觸發第 2 張）
- [ ] 畫面跳出獎勵通知，獎勵中心票券數量增加

### 1.5 修改習慣名稱
- [ ] 點擊習慣卡片資訊區 → 進入管理頁面
- [ ] 修改「項目名稱」欄位 → 返回追蹤頁確認名稱已更新

## 二、分析頁面 (Analytics)

### 2.1 進度條與階段
- [ ] 每個習慣顯示階段進度條（每 50 次一個階段）
- [ ] 「每日閱讀」45 次 → 階段 1，進度 45/50（90%）
- [ ] 「深蹲運動」120 次 → 階段 3，進度 20/50（40%）

### 2.2 28 天熱力圖
- [ ] 每個習慣下方顯示 28 格迷你熱力方塊
- [ ] 深蹲運動因次數多，應顯示較多深色方塊
- [ ] 冥想練習（僅近 14 天有資料）前 14 格為空白

### 2.3 無資料提示
- [ ]（可選）清除所有習慣後，分析頁面顯示「尚未有足夠數據進行分析」

## 三、專注頁面 (Focus)

### 3.1 統計儀表板
- [ ] 載入測試資料後，儀表板顯示本週累計與歷史總計
- [ ] 今日累積數字正確（依測試當天是否有專注紀錄而定）

### 3.2 抽獎券進度條
- [ ] 專注獎勵進度條顯示目前進度
- [ ] 總分數接近 420 分鐘時，顯示橘色提示「再專注 X 分鐘即可獲得獎券！」

### 3.3 番茄鐘模式
- [ ] 預設選中「番茄鐘」按鈕，顯示 25:00
- [ ] 點擊「開始專注」→ 倒數開始，進度環動態更新
- [ ] SVG 圓環從滿到空（25 分鐘完整倒數）
- [ ] 點擊「結束專注」→ 計時停止，時間重置為 25:00

### 3.4 正向計時模式
- [ ] 點擊「正向計時」→ 確認切換對話框
- [ ] 時間顯示切換為 00:00，模式標籤變為「正向計時中」
- [ ] 點擊「開始專注」→ 秒數向上累加
- [ ] 點擊「結束專注」→ 彈出通知顯示已紀錄分鐘數
- [ ] 專注紀錄寫入 focusLogs，儀表板與進度條更新
- [ ] 時間重置為 00:00

### 3.5 模式切換守衛
- [ ] 計時進行中點擊模式切換 → 跳出確認對話框
- [ ] 確認 → 計時停止，模式切換，時間重置
- [ ] 取消 → 計時繼續，模式不變

### 3.6 長亮護眼模式
- [ ] 開啟「長亮護眼模式」toggle
- [ ] 點擊「開始專注」→ 畫面變為全黑覆蓋層，僅顯示極暗的時鐘數字
- [ ] 點擊黑色畫面 → 恢復正常顯示，出現「返回護眼畫面」按鈕
- [ ] 點擊「返回護眼畫面」→ 再次進入全黑覆蓋層
- [ ] 關閉 toggle → 返回按鈕消失

### 3.7 補登專注時間
- [ ] 點擊「手動補登專注時間」→ 彈出日期與分鐘數表單
- [ ] 填入日期與分鐘數 → 確認 → 紀錄寫入，儀表板更新

## 四、獎勵頁面 (Rewards)

### 4.1 抽獎券顯示
- [ ] 右上角顯示持有 3 張抽獎券
- [ ] 抽獎箱顯示 🎁 圖示

### 4.2 抽獎功能
- [ ] 點擊「開始抽獎」→ 按鈕變為 disabled，箱子震動動畫
- [ ] 約 0.6 秒後彈出結果通知（含稀有度與獎項名稱）
- [ ] 票券數量 -1
- [ ] 抽中的獎項出現在背包清單中

### 4.3 票券不足
- [ ] 將票券用完（抽 3 次後）再點擊抽獎 → 跳出「抽獎券不足！」

### 4.4 獎池管理
- [ ] 點擊「獎池」→ 顯示三個稀有度的編輯區
- [ ] 修改獎池內容（逗號分隔）→ 儲存 → 後續抽獎使用新獎池

### 4.5 背包管理
- [ ] 背包顯示 4 件測試獎品，依稀有度顯示不同邊框顏色（綠/藍/橘）
- [ ] 點擊獎品 → 彈出編輯視窗，可修改名稱與稀有度
- [ ] 點擊「移除此項」→ 確認後刪除
- [ ] 點擊「手動新增」→ 可新增任意獎品到背包

### 4.6 獎池為空防禦
- [ ] 清除所有獎池內容後抽獎 → 跳出「獎池為空！請先到管理獎池設定獎勵。」

## 五、資料管理 (Backup)

### 5.1 匯出備份
- [ ] 點擊「匯出備份檔案」→ 下載 JSON 檔案
- [ ] 檔案命名格式：`habitflow-pro-backup-YYYY-MM-DD.json`

### 5.2 複製代碼
- [ ] 點擊「複製代碼模式」→ 跳出「JSON 代碼已複製！」
- [ ] 貼到文字編輯器確認內容為完整 JSON

### 5.3 代碼還原
- [ ] 點擊「輸入代碼還原」→ 貼上先前複製的 JSON → 確認 → 資料還原

### 5.4 拖曳匯入（桌面端）
- [ ] 將 `.json` 備份檔拖入 drop zone 虛線框
- [ ] 拖曳時框線變色（紫色高亮）
- [ ] 放開後顯示綠色成功訊息
- [ ] 資料正確匯入

### 5.5 點擊匯入（手機端）
- [ ] 點擊 drop zone → 檔案選擇器彈出
- [ ] 選取 `.json` 檔 → 顯示綠色成功訊息

### 5.6 匯入錯誤處理
- [ ] 選取非 `.json` 檔案 → 紅字提示「僅接受 .json 備份檔案」
- [ ] 選取格式錯誤的 JSON → 紅字提示「JSON 格式解析失敗」
- [ ] 選取缺少 `habits` 欄位的 JSON → 紅字提示「資料缺少 habits 陣列」

## 七、跨頁面整合

- [ ] 底部導航列四個頁籤切換正常，當前頁籤高亮
- [ ] 在習慣頁紀錄成就 → 若觸發票券 → 切到獎勵頁確認票券數量
- [ ] 在專注頁累積滿 7 小時 → 獎勵頁票券 +1

## 已知限制

- Android 瀏覽器不支援拖曳，僅能點擊 drop zone 選取檔案
- 番茄鐘中途停止不記錄部分進度（by design）
- 撤銷 / 刪除紀錄不會退還已發放的抽獎券
- `alert()` / `confirm()` 在 fullscreen 模式下可能無法正常顯示
